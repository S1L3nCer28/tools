# 样品进度看板（内部服务器版）

这是一个与仓库现有网页隔离的独立网站，入口由服务器提供。仓库只保存程序代码；账号密码和样品数据保存在内部服务器。

## 安全与本地版

- 本地原有的 HTML 看板继续直接打开使用，不需要登录。
- 网站版必须运行在公司内部服务器，并通过 HTTPS 或 HTTPS 反向代理访问。
- 不要把 `.env`、`data/` 或导出的样品备份提交到 GitHub。此仓库是公开的。
- 首次启动前复制 `.env.example` 为 `.env`，填写服务器端的 `SEED_PASSWORD`。用户 `husitian` 会在首次启动时创建，密码以带随机盐的 scrypt 摘要保存。
- 后续新增用户可在服务器端更新 `data/users.json`：每个用户使用 `salt` 与 `passwordHash` 字段（十六进制）。密码不会存入仓库或明文账号库。

## 启动

需要 Node.js 22 或更新版本。首次启动前在服务器上设置环境变量，或复制 `.env.example` 为未提交的 `.env` 文件。生产环境需在 HTTPS 反向代理后启动：

```sh
node --env-file=.env server.mjs
```

默认端口为 3000。内部服务器反向代理应保留原始 `Host`，并设置 `X-Forwarded-Proto: https`。服务器数据目录默认是 `./data`，请纳入公司内部备份，不要放到 GitHub。

## 迁移本机样品数据

本地 HTML 文件把样品保存在当前浏览器的本地存储中，网站登录不会自动读取这份数据。先在本地看板点“数据备份”，登录网站后点“恢复备份”导入到 `husitian` 账号。导入后网站会同步到内部服务器。

## 部署限制

GitHub Pages 只能托管静态文件，不能运行这里的登录 API 或保护样品数据。请把此应用部署到公司内部 Node.js 服务器；GitHub 用于保存版本代码。
